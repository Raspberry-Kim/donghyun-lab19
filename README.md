- 그림·효과음·음성은 EA가 2008년에 무료로 푼 판의 기본 자료다. [EA의 모딩 지침](https://www.ea.com/games/command-and-conquer/news/modding-faq)에 따라 무료·비영리로만 나누고, 음악 파일은 넣지 않았다. EA는 이 허락을 언제든 거둘 수 있다. 그래서 **원작 자료는 이 저장소에 없다.** 자료 전용 저장소에 따로 두었고, EA가 원하면 바로 내린다.
- **데스크톱에서, 마우스와 키보드로, 전체 화면으로** 하기를 권한다. 휴대폰·태블릿에서는 손가락으로 유닛을 고르고 명령하기가 어렵다.
- 캠페인·영상·음악·여럿이 하는 전투는 없다. 게임 안의 글자와 음성은 영어다.

## 동현레 규약

동현랭 코드가 출력한 **정수 일곱**이 차례로 출전 설정이다.

| 차례 | 뜻 | 범위 | 기본값 |
|---|---|---|---|
| 1 | 내 진영 | 1 러시아 · 2 영국 · 3 우크라이나 · 4 독일 · 5 프랑스 | 1 |
| 2 | 상대 진영 | 1–5 (위와 같음) | 2 |
| 3 | 시작 자금 | 500–10000 | 5000 |
| 4 | 기술 수준 | 1–10 | 10 |
| 5 | 컴퓨터 실력 | 1 쉬움 · 2 보통 · 3 어려움 | 2 |
| 6 | 지도 | 1 풀밭 · 2 큰 호수 · 3 두 호수 사이 · 4 바닷가 · 5 눈밭 · 6 얼음 연못 | 1 |
| 7 | 시작 유닛 수 | 0–12 | 2 |

- 출력이 없으면 기본값 `1 2 5000 10 2 1 2`로 나선다.
- 일곱 개가 아니거나 범위를 벗어나면 나서지 않고 오류를 알린다.
- 내 진영과 상대 진영에 같은 번호를 써도 된다.
- 상대의 건물과 유닛이 하나도 남지 않으면 이기고, 내 것이 하나도 남지 않으면 진다.

예제는 여섯이다: 기본(러시아 대 영국 · 풀밭), 화력과 연사(독일 대 프랑스 · 큰 호수), 느긋한 첫 전투(영국 · 쉬움), 초반 장비만(기술 수준 2 · 눈밭), 가난한 전쟁(자금 2500 · 어려움), 계산해서 정하기(시작 자금 = 기술 수준 × 800 + 2000).

## 진영 다섯

진영마다 남보다 나은 점이 꼭 한 가지씩 있다. 원작의 규칙 그대로다.

| 번호 | 진영 | 편 | 나은 점 |
|---|---|---|---|
| 1 | 러시아 | 소련 | 값이 10% 싸다(값 × 0.9) |
| 2 | 영국 | 연합 | 10% 단단하다(받는 피해 × 0.909) |
| 3 | 우크라이나 | 소련 | 10% 빠르다(지상 속도 × 1.1) |
| 4 | 독일 | 연합 | 화력이 10% 세다(화력 × 1.1) |
| 5 | 프랑스 | 연합 | 10% 빨리 쏜다(재장전 시간 × 0.909) |

소련 편은 중전차·맘모스 전차·V2 로켓·테슬라 코일·미그·잠수함을, 연합 편은 경전차·중형 전차·자주포·포탑·롱보우·구축함·순양함을 쓴다. 건물·유닛·탄두의 값은 페이지의 ‘조작과 진영’ 탭에 표로 적었다.

## 조작

| 입력 | 하는 일 |
|---|---|
| 마우스 왼쪽 버튼 | 고르기 · 이동 · 공격 · 사이드바에서 짓기 |
| 왼쪽 버튼 끌기 | 여럿 고르기 |
| 마우스 오른쪽 버튼 | 고른 것 풀기 |
| `←` `↑` `↓` `→` | 지도 옮기기(누르고 있으면 60밀리초에 한 칸). 키보드가 페이지 쪽에 있어도 전투 중이면 듣는다. 코드 칸에 글자를 적는 중에는 커서를 옮긴다 |
| `Space` · `Esc` | 메뉴(Save Mission · Load Mission · Game Controls · Abort Mission · Resume Mission) |
| `Ctrl`+`1`–`0` · `1`–`0` | 부대 묶기 · 부르기 |
| `H` · `Home` | 내 기지로 · 고른 유닛으로 화면 옮기기 |
| `S` `X` `G` `F` | 멈춤 · 흩어지기 · 경계 · 대형 |
| `T` · `Y` | 고치기 · 팔기 |
| `PageUp` · `PageDown` | 사이드바 목록 올리기 · 내리기 |

전체 화면에서는 `Esc`가 전체 화면을 닫으므로 메뉴는 `Space`로 연다. 효과음과 음성은 게임 화면을 한 번 클릭하면 켜진다.

## 저장과 불러오기

게임 화면 아래의 **저장**을 누르면 전투가 멎고 메뉴가 뜬다. 브라우저 칸 셋 가운데 하나에 적거나 `.dhsave` 파일로 내려받는다. **불러오기**는 칸이나 파일에서 그 전투를 되살린다. 진영·지도·자금은 저장할 때 그대로이고 편집기의 코드는 바뀌지 않는다. 전체 화면에서도 같은 버튼이 화면에 함께 뜬다. 저절로 저장하지는 않는다.

- 브라우저 칸(`localStorage`의 `donghyunre.slot.1`–`3`)은 이 기기의 이 브라우저에만 남는다. 오래 두거나 옮기려면 파일로 내려받는다.
- 저장 파일(`donghyunre-save-1`)에는 엔진이 쓴 저장 파일(약 170KB)이 통째로 들어간다. 묶음 하나가 약 22만 글자다. 엔진이 바뀐 뒤의 판에서는 읽지 못할 수 있다.
- 게임 안의 메뉴(Options)가 열려 있으면 저장되지 않는다. 닫고 누른다.

게임 안의 메뉴로도 저장할 수 있다(Save Mission). 엔진이 쓴 저장 파일을 `re/game.html`이 이 브라우저의 보관함(IndexedDB)에 옮겨 두고, 다음에 열면 전장 화면에 **이어하기** 버튼이 나온다. 다른 브라우저·기기로는 옮겨지지 않고, 사이트 자료를 지우면 함께 지워진다.

## 원작과 다르게 한 곳

- 제목 화면과 메뉴를 거치지 않고 코드의 값으로 바로 전투를 연다.
- 컴퓨터의 진영을 코드로 정한다.
- 1:1 전투도 저장하고 이어 할 수 있게 열었다. 페이지의 저장·불러오기 버튼이 엔진의 저장 파일을 주고받고, 메뉴가 떠 있는 동안 전투를 멈춘다.
- 방향키로 지도를 옮긴다. 사이드바 목록은 PageUp·PageDown으로 옮겼다. 방향키를 누르는 동안에는 포인터가 가장자리에 있어도 방향키를 따른다. 키보드가 페이지 쪽에 있을 때 누른 방향키는 페이지가 게임에 넘긴다.
- 포인터가 게임 화면 밖에 있으면 지도가 움직이지 않는다. 끌다가 화면 밖에서 버튼을 놓아도 같다. 사이드바를 처음부터 열어 둔다.
- 시작 자리는 지도에 적은 두 곳만 쓴다.
- 지도 여섯 장은 내가 새로 만들었다(`engine/maps/mkmaps.py`). 원작의 지도는 쓰지 않았다.
- 음악을 고르는 기능을 껐다.

## 파일 구성

- `index.html`: 화면·편집기·문서·글꼴·아이콘·지도 얼개 그림을 묶은 한 장(약 3.9MB, `node build.cjs`로 만든다).
- `re/`: 게임 엔진(`re.js`·`re.wasm`), 엔진을 띄우는 `game.html`, 지도 여섯 장 `maps.js`. 출전을 누를 때만 불러온다.
- `engine/Vanilla-Conquer/`: 고친 엔진 소스 전체. `engine/donghyun-re.patch`: 고친 부분. `engine/build.sh`: 빌드 방법.
- `engine/maps/`: 지도 생성기와 지도 파일. `engine/tables/tables.json`: 엔진에서 꺼낸 건물·유닛·탄두 값. `engine/pack-data.py`: 원작 자료를 한 덩어리로 잇는 스크립트.
- `src/`: 화면 원본. `qa/`: 시험. `licenses/`: 라이선스 원문.

원작 자료(`re.data`, 18,906,225바이트)는 자료 전용 저장소 `donghyun-re-data`에서 받는다. `re/game.html`은 github.io에서는 `/donghyun-re-data/`에서, 그 밖에서는 옆 폴더 `data/`에서 받는다.

## 내 컴퓨터에서 돌리기

원작 자료가 있어야 한다. [OpenRA 목록](https://github.com/OpenRA/OpenRA/blob/bleed/mods/ra-content/installer/downloads.yaml)의 `basefiles` 꾸러미(SHA-1 `aa022b208a3b45b4a45c00fdae22ccf3c6de3e5c`)를 받아 풀고, 안의 MIX 파일 11개를 한 덩어리로 잇는다.

```
python3 engine/pack-data.py <MIX 파일이 든 폴더>   # data/re.data, data/re.data.json을 쓴다
python3 -m http.server 8000                        # http://127.0.0.1:8000/ 을 연다
```

`data/` 폴더는 `.gitignore`에 넣어 저장소에 올라가지 않게 했다.

## 엔진

[Vanilla Conquer](https://github.com/TheAssemblyArmada/Vanilla-Conquer)(커밋 `9103a8e`)를 고쳐 Emscripten 3.1.1로 묶었다. Vanilla Conquer의 바탕은 EA가 공개한 [원작 소스](https://github.com/electronicarts/CnC_Red_Alert)다. 브라우저용 수정은 [midzer의 emscripten 가지](https://github.com/midzer/Vanilla-Conquer)를 참고했다.

고친 곳(파일 14개, 새 파일 2개):

- `redalert/dhweb.cpp`·`dhweb.h`(새 파일): 코드의 일곱 값을 받아 1:1 전투를 바로 열고, 승패와 저장을 페이지에 알리고, 페이지가 시킨 저장·멈춤·불러오기·방향키를 받고, 진영 배율·규칙 값·건물·유닛·탄두 값을 꺼내 준다.
- `redalert/init.cpp`·`startup.cpp`·`scenario.cpp`: 메뉴를 건너뛰고 바로 시작하기, 컴퓨터 진영 정하기, 시작 자리 두 곳.
- `redalert/goptions.cpp`·`loaddlg.cpp`·`event.cpp`: 1:1 전투의 저장과 불러오기.
- `redalert/scroll.cpp`: 방향키로 지도 옮기기(가장자리 밀기보다 먼저), 포인터가 화면 밖일 때 지도 멈추기.
- `redalert/theme.cpp`·`conquer.cpp`: 음악 고르기 끄기, CD 확인 건너뛰기.
- `common/mssleep.h`·`wwkeyboard.cpp`·`wwstd.h`, `CMakeLists.txt`: 브라우저 빌드에 필요한 수정.

## 빌드와 시험

```
node build.cjs              # dist/와 루트 index.html(GitHub Pages용) 생성
node qa/core-tests.cjs      # 예제 출력, 규약 판정, 지도 파일, 페이지의 표와 엔진 값
node qa/engine-tests.cjs    # 브라우저(Chromium)에서 엔진과 페이지를 실제로 띄워 확인(Playwright, data/ 폴더 필요)
bash engine/build.sh        # 엔진 다시 만들기(Emscripten 3.1.1, cmake, ninja)
```

엔진 시험은 바로 시작하기, 다섯 진영의 배율, 방향키(키보드가 게임에 있을 때와 페이지에 있을 때, 끌다가 화면 밖에서 놓은 뒤), 건설과 값, 전력, 컴퓨터의 건설, 메뉴, 저장과 이어하기, 페이지의 저장 칸과 불러오기, 승패 알림, 지도 여섯 장을 본다. 모두 자동 실행이다. 사람이 한 판을 끝까지 해 본 것은 아니고, 실제 기기의 마우스·키보드·소리도 내가 직접 확인하지 못했다.
